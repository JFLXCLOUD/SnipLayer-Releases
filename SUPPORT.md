# SnipLayer support

## Before reporting a problem

1. Exit SnipLayer from its notification-area menu, then reopen it.
2. Confirm the shortcut in **Settings** is not reserved by another application.
3. Reproduce the problem once using non-sensitive sample content.
4. Open **Settings > Copy diagnostics** and review the text before attaching it.

Diagnostics do not contain screenshots or clipboard contents, although Windows error details can contain local paths.

Use the [public issue tracker](https://github.com/JFLXCLOUD/SnipLayer-Releases/issues/new/choose) for bugs and focused feature requests. Never attach a sensitive screenshot merely to demonstrate a capture problem; recreated sample content is usually enough.

For vulnerabilities or reports containing exploit details, use [private vulnerability reporting](SECURITY.md), not a public issue.
