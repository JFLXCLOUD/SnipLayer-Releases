# Security policy

Do not open a public issue for a vulnerability, exploit details, credentials, or private user data.

Use the repository's **Security > Report a vulnerability** flow to submit a private report. Include the affected SnipLayer version, Windows version, impact, reproduction steps, and any safe supporting material. Do not include real sensitive screenshots.

The project will acknowledge valid private reports and coordinate remediation before public disclosure. Formal response-time targets will be published before the final 1.0 release.
